## 안전한 시간 예산 정책
- 한 사람이 동시에 KIC·PayPal·UGREEN을 진행하고 있을 수 있다. **이 표는 UGREEN만**의 계획/별도 장애 예비 시간이다. 통합 총괄이 KIC/PayPal 일정과 합산해야 한다.
- 계획시간 = 그날 **작게 나눈 순수 작업**; 예비시간 = 별도로 확보할 수 있는 검사/오류 복구 한도. **실제로 사용한 시간이 아니다**. 고객 민감 데이터·유료 클라우드/하드웨어 사용 없이 작업.
- 11/17~20은 **초청 전, 선택적인 낮은 비용의 대비 작업**이다. 11/21 미선발이면 이후 본선 작업 취소. 11/22~28 각 날짜는 **배정되지 않았다면** 표의 준비 작업, 배정됐다면 **T(접속 첫날) + T+1(다음날) 특수작업으로 완전 대체**한다. 중복 합산하지 않는다.
- 60~90분 무진전 시 동일 반복 중지, 증거/장애·지원 연락 기록. 일일 상한 도달은 `PARTIAL/BLOCKED` 기록 후 재산정. SDK·NAS 지원이 영원히 막히면 12시간을 써도 실기 성공을 보장할 수 없으므로 **시간 예산과 실현 가능성은 별개**이다.
- 최종 제출 직전은 새 기능 추가보다 진짜 NAS 호환성·영상·영수증이 우선. 최종 영상이 배정일 전에 촬영된 모의 영상이면 안 된다.

### 합계 및 배정일 덮어쓰기 계산
- **기본표 합계:** 계획 **32h** + 별도 예비 **20.5h** = 최대 **52.5h** (11/17~12/01, 매일 표의 모든 일을 실제로 하라는 뜻이 아님).
- 특수 배정일 24h 접근은 **T일과 T+1일**에 걸쳐, **계획 6h + 별도 예비 6h = 최대 12h의 실제 작업량**으로 계획한다. 이때 두 날짜의 일반 표 시간을 **빼고 12h를 넣는다**.
- 배정일이 11/22~27이면 일반 두 날짜의 최대 **6h**를 12h로 대체 → 총 상한 **58.5h**. 11/28 배정이면 11/28(3h)+11/29(7h)를 12h로 대체 → 총 상한 **54.5h**. 이 두 총액은 **동시에 더하지 않는 대안 시나리오**이며, 진짜 접근/영상/오류 상태에 따라 재추정한다. 11/29 T+1일을 NAS에 사용하면 일반 편집 작업은 11/30로 이월해야 하므로 **11/28 늦은 슬롯이 더 위험하다**.
- 위 예비 소모는 최대 허용 가정일 뿐 필수 근무가 아니다. 24시간 NAS 접근을 24시간 연속 노동으로 전제하지 않는다. 12시간 노동을 넘겨야 하는 접근 장애는 심각한 위험이며, 야간 수면·안전도 고려한다.

## T/T+1: 유일한 실제 NAS 배정 세션 (두 날짜 일반 일정 대체)
**T(배정일, KST 17:00 전후 시작 / 실제 이메일 기준):**
1. 첫 1h: 로그인/연결 상태, 권한·데이터 스코프 확인, 미리 준비한 테스트 파일 배치(비개인정보), Skill 설치/기본 호출. **실 NAS/Skill이 실행되는지 처음 2h 이내 객관적 판정**.
2. 이후 2h: 완료된 납품 폴더로 정상 READY 흐름 실행; 결과 근거·화면·로그 확보.
3. 이후 1~2h: 누락 파일, 버전 충돌, 접근거부/NOT_CHECKED 에지 케이스 검수. **계획 3h + 여분 최대 2h**(합계 5h 이내).
4. 연결이 끊기면 무한 설치 재시도를 하지 않고 장애 화면·지원 로그 기록, 1회 합리적 복구/공식 지원 연락. 원본/사용자 데이터 영구 수정 금지.

**T+1(다음 날, KST ~16:59 또는 계정 만료 직전):**
1. 계획 3h: **NAS 실제 실행 장면**, 입출력과 사용자 가치가 보이는 핵심 워크플로 녹화; 미검증/문제가 있으면 장면을 조작하지 않고 사실대로 보여줌.
2. 여분 최대 4h: 재현성 확인, 음성 없는 원본 영상/캡처/CLI 로그·샘플 보고서 NAS 외부 안전한 허가된 위치에 백업, 최종 후보 SHA와 영상 원본 이름을 기록. 1h 이상 **접근 종료 전에 정리 완료**.
3. **총 배정 세션 계획 6h + 예비 6h = 최대 12h**. 위 24h 창의 나머지는 휴식·수면·통신 장애/외부 지원 회신용 시간으로 보호; 체력과 서비스 상태에 따라 세션 내 배분을 조정할 수 있다.
