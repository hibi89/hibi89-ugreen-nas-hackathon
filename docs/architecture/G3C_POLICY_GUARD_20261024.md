# G3c preliminary read-only policy gate (advance work — 2026-10-24)
This is **independent local test code**, not actual NAS rights verification or sensitive-content scanning.
Module `src/projectready/policy_guard.py` implements conservative eligibility for a user-selected folder. It requires explicit metadata consent, separate content consent and a validated official adapter before reporting `ELIGIBLE_FOR_ADAPTER_CHECK`. That value only means that a future adapter may be considered; it **never** means a file was read, the operation succeeded or the content is safe. `CHANGE` and `TRANSFER` are categorically blocked in v1. All outputs keep `sensitive_content_check=NOT_CHECKED`.
Source: `tests/test_policy_guard.py`, fully synthetic. The official kit's command signatures/agent registry/PII capability remain unverified. These Python scripts must not appear in the official SKILL.md-only Round 1 submission archive. The actual G3c integration and security behavior remain scheduled for **2026-11-01~02**.
