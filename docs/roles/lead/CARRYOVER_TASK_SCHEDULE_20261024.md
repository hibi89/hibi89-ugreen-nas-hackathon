## 차단/지연 시 강제 처리
- G1 명세가 10/25~26에 확보되지 않을 수 있으며 **10/27 결정 게이트에서도 미해결 가능**. 그때 **SDK_BLOCKED**를 사실대로 공시하고, 지원 가능한 별도 합성 테스트·영문 제안서 문안·검증 설계는 계속 수행할 수 있다.
- 이미 선행 개발한 G2/G3b의 코드를 다시 처음부터 만드는 일을 진척으로 표시하지 않는다. 공식 호환성 보강이 끝날 때까지 **정식 기능 완료가 아니라 독립 프로토타입 검증 성공**이다.
- SDK가 막히면 무한정 임의 시간 예산을 초과하지 않고 (같은 방법 두 번 실패 또는 60~90분 무진전 시 중단), 공식 기술 지원·증거 있는 대안·주최 규정 재확인 순으로 전환한다. 대회 참가비 외 승인 없는 지출 없음.
- 매 호출 종료 시 [DAILY_PROGRESS.md](DAILY_PROGRESS.md)의 해당 날짜 **100% 분모/완료율·잔여시간**을 다시 기록하되 **G1 게이트 상태와 분리**한다. 날짜가 도래하지 않은 업무는 0%/NOT_STARTED이지 누락이나 성공이 아니다.

**2026-10-24 검증 기준:** `lead/ugreen`의 독립 코드와 [GitHub Actions 68 PASS](https://github.com/hibi89/hibi89-ugreen-nas-hackathon/actions/runs/40065789384). 실제 공식 등록 Expert Agent 호출, NAS 실제 실행, ZIP/PDF 최종 제출 영수증은 **미검증/미완료**.

이 문서는 [기존 마스터 일별 시간표](../../UGREEN_DAILY_EFFORT_PLAN_20261024.md)의 일자·기준 계획시간을 바꾸지 않고, **건너뛰었다고 인식되기 쉬운 날짜의 복귀 작업**만 명시한다.
